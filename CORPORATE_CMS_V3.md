# Plekxa Enterprise OS v3 — Corporate CMS

Run `supabase/migrations/008_corporate_cms_v3.sql` once in the shared Supabase project.
This migration is additive and preserves all Studio and Enterprise tables and records.

Enterprise now manages homepage sections, website pages, navigation, media URLs, leadership, events, brand/SEO settings, newsroom article bodies and images, and careers content.
The Corporate v3 website reads the same tables and automatically displays published content.
