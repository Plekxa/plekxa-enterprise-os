# Plekxa Enterprise OS v3.7.0

Operational scale release.

- Marketing Asset Release Queue: searchable approved Assets, newest-first, status/profile filters, release date and Plekxa Profile scheduling, deliverable visibility.
- Distribution gate: a Release cannot be created until Marketing has scheduled the Asset; Distribution inherits Marketing's release date/profile.
- Team Files: search, department/category filters, sort and upload date.
- Finance: searchable ledger, date/status filtering, Asset identification and visible 70/30 waterfall.
- Analytics: Plekxa retained 70%, Index pool 30% and outstanding allocations from live finance data.
- Taxonomy display: R&B is rendered as R&B rather than the internal `r_b` key in shared UI.
- Additive `asset_release_controls` migration; no master files are moved or copied.
