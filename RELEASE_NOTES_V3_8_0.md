# Plekxa Enterprise OS v3.8.0

- Communication identifies creators by name and deduplicates active creator-role workspaces in the Project Hub.
- Prevents duplicate direct commissions for the same creator/project/role and reuses an existing contributor workspace when an application is accepted.
- Application decision buttons now reflect state: accepted/rejected applications no longer show Shortlist/Accept/Reject.
- Adds Remove from project for contributors and Remove Director while preserving historical records.
- Adds Block platform access / Unblock creator in Creator Directory. Blocking sets operational_status=blocked and bans the linked Supabase auth user.
- Projects list adds All projects / Assigned to me filtering using existing work_assignments.
