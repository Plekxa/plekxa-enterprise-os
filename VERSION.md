# Plekxa Enterprise OS v3.2.2

Targeted fixes:
- Replaced six disabled asset upload inputs with one optional multi-file uploader.
- New assets may queue files before the asset record exists; files upload after Save asset.
- Existing uploaded files display below the uploader and can be opened or removed.
- Contributors are optional; ownership validation applies only when contributor details are supplied.
- Application and command-centre metric labels and numbers are visually separated.
- Expanded supported asset formats.
